## 3. Теоретическое обоснование

`QTimer` — класс Qt, который по истечении заданного интервала излучает сигнал `timeout()`. Интервал задаётся в миллисекундах. Метод `start()` запускает повторяющийся таймер, `start(ms)` запускает таймер с указанным интервалом, а `stop()` останавливает его. Метод `setInterval()` позволяет изменить интервал, `isActive()` — проверить состояние таймера. Для однократного вызова можно использовать `QTimer::singleShot()`.

Таймер работает в цикле событий Qt. В GUI-приложении цикл запускается вызовом `app.exec()`. Он принимает и обрабатывает события, в том числе срабатывания таймера и нажатия мыши. Если цикл событий не запущен, таймер и обработка событий интерфейса не работают.

В Qt можно подключать сигналы к лямбда-функциям. В списке захвата указывается, какие внешние переменные использует лямбда. Захват `[=]` копирует значения, `[&]` захватывает переменные по ссылке, `[this]` позволяет обращаться к полям и методам объекта. Захват по ссылке опасен, если локальная переменная уничтожается раньше лямбда-функции.

Третий аргумент `connect()` — контекст подключения. Если контекст уничтожается, Qt автоматически разрывает соединение. Это защищает от вызова лямбда-функции, которая обращается к уже уничтоженному объекту.

`QMetaObject::Connection` хранит идентификатор соединения. С его помощью можно разорвать конкретное соединение через `disconnect(conn)` и затем создать новое. Это используется при переключении режима таймера и при очистке динамической палитры.

События и сигналы в Qt отличаются. `mousePressEvent()` — виртуальный метод, который вызывается системой событий при нажатии мыши. К нему нельзя подключиться через `connect()`. Внутри обработчика события виджет может излучить собственный сигнал, например `colorChanged(QColor)`, который уже подключается к слоту или лямбда-функции.

## 4. Реализация

Интерфейс и логика приложения созданы на C++ с использованием Qt Widgets. Интерфейс формируется в коде, без файла `.ui`. В проекте используются классы `MainWindow`, `ColorWidget` и `PaletteButton`.

### Таймер и режимы

В главном окне хранится объект `QTimer`. При запуске таймер вызывает обработчик, который выбирает действие в зависимости от текущего режима:

```cpp
m_timeoutConn = connect(&m_timer, &QTimer::timeout, this, [this]() {
    switch (m_mode) {
    case Mode::Cycle:  m_canvas.stepForward();     break;
    case Mode::Random: m_canvas.setRandomColor();  break;
    case Mode::Blink:  m_canvas.toggleBlink();     break;
    }
});
```

Перед переподключением старое соединение разрывается через `disconnect(m_timeoutConn)`. Текущий режим хранится в поле `m_mode`, поэтому лямбда использует актуальное состояние объекта.

### Динамические кнопки и очистка палитры

Кнопки цветов создаются во время работы приложения. Для каждой кнопки создаётся соединение сигнала `clicked()` с лямбда-функцией, которая добавляет цвет в палитру холста. Идентификаторы соединений сохраняются в `QMetaObject::Connection`.

При очистке палитры сначала разрываются сохранённые соединения, затем кнопки удаляются через `deleteLater()`. Для хранения указателей на динамические кнопки используется `QPointer`, который позволяет проверить, существует ли объект.

### Обработка мыши и переподключение сигнала

Холст обрабатывает нажатия мыши через `mousePressEvent()`. При нажатии меняется текущий цвет и излучается сигнал `colorChanged(QColor)`. Главное окно подключает этот сигнал к одному из двух обработчиков: обновлению строки статуса или изменению заголовка окна. Кнопка переключения обработчика разрывает прежнее соединение и создаёт новое.

## 5. Пример работы программы

При запуске открывается окно ColorSwitcher с холстом, строкой состояния, текущим интервалом и режимом, а также кнопками управления.

Проверены следующие действия:

1. Нажатие «Старт/Стоп» запускает таймер; повторное нажатие останавливает его.
2. «Медленнее» увеличивает интервал таймера.
3. «Быстрее» уменьшает интервал таймера.
4. Кнопка «Режим» переключает режимы «Цикл», «Случайный» и «Мигание».
5. В режиме «Цикл» холст последовательно меняет цвет.
6. В режиме «Случайный» холст получает случайный цвет.
7. В режиме «Мигание» холст переключается между цветом и чёрным.
8. Левый и правый клики по холсту переключают цвет вперёд и назад.
9. Кнопка «+ Цвет» добавляет новую кнопку цвета; нажатие на неё добавляет цвет в палитру.
10. «Очистить палитру» удаляет динамические кнопки, а «Сменить обработчик клика» меняет действие сигнала холста.

В приложении также предусмотрены сообщения `qDebug()` для отображения срабатываний таймера, динамических соединений, кликов и удаления объектов.

## 6. Ошибки и способы их решения

При работе с таймерами и динамическими соединениями важно учитывать следующие ошибки:

- **Таймер не срабатывает.** Причина может быть в отсутствии цикла событий. Для GUI-приложения в `main()` необходимо запускать `app.exec()`.
- **Лямбда обращается к уничтоженной переменной или объекту.** Для локальных значений используется захват по значению, а для обращения к объекту — захват `this` вместе с контекстом подключения.
- **Обработчик вызывается несколько раз.** Это может происходить при повторном подключении одного сигнала без разрыва старого соединения. Перед созданием нового соединения нужно отключить сохранённый `QMetaObject::Connection`.
