# ColorSwitcher

Небольшое приложение на C++ и Qt Widgets для переключения цвета холста. Проект выполнен в рамках лабораторной работы №3 по теме «QTimer, лямбда-слоты и динамические соединения».

## Возможности

- Переключение цветов по таймеру.
- Три режима: последовательный переход по палитре, случайный цвет и мигание.
- Изменение интервала таймера.
- Переключение цвета щелчками мыши: левая кнопка — следующий цвет, правая — предыдущий.
- Добавление цветных кнопок во время работы программы и подключение их сигналов.
- Очистка динамической палитры с разрывом соединений.
- Переподключение сигнала холста к другому обработчику без пересоздания холста.

## Сборка и запуск

1. Откройте файл `ColorSwitcher.pro` в Qt Creator.
2. Выберите установленную версию Qt с модулем Qt Widgets.
3. Выполните сборку проекта.
4. Запустите приложение.

Для ручной сборки через qmake:

```bash
qmake ColorSwitcher.pro
make
./ColorSwitcher
```

Для Windows имя исполняемого файла может отличаться в зависимости от используемого комплекта сборки.

## Структура проекта

- `main.cpp` — создание приложения и запуск цикла событий.
- `colorwidget.h/.cpp` — холст, палитра, отрисовка и обработка нажатий мыши.
- `palettebutton.h/.cpp` — кнопка, хранящая выбранный цвет.
- `mainwindow.h/.cpp` — интерфейс, таймер и динамические соединения.
- `ColorSwitcher.pro` — настройки проекта qmake.

## Используемые средства Qt

В работе используются `QTimer`, лямбда-функции в `connect()`, `QMetaObject::Connection`, `disconnect()`, `QPointer`, `deleteLater()`, собственный сигнал `colorChanged()` и переопределение `mousePressEvent()`.
